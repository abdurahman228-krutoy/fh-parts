# FH Parts: сайт-каталог запчастей

Статический сайт (HTML, CSS, JS), без сборки. Работает на GitHub Pages.

## Запуск локально

```bash
cd site
python3 -m http.server 8123
```

Открыть http://127.0.0.1:8123/

## Настройка WhatsApp

Файл `js/config.js`:
- `whatsappNumber`: номер менеджера цифрами с кодом страны, например `"971501234567"`. Тогда кнопка откроет личный чат и подставит данные товара.
- Если номер пустой, откроется группа, а текст заявки скопируется в буфер обмена.

## Добавить товар

1. Положите фото в `img/` (квадрат 900×900).
2. Скопируйте любой блок в `data/products.js` и поправьте поля.

## Деплой на GitHub Pages

Settings → Pages → Branch: `main`, папка `/ (root)`.
